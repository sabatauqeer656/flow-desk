## Features

- User signup and login
- JWT authentication
- HTTP-only cookie security
- Refresh token system
- Protected routes
- AI movie search
- AI hobby recommendations
- Vector similarity search

## Tech Stack

Frontend:
- React
- JavaScript
- Tailwind CSS
- Axios

Backend:
- Node.js
- Express.js
- MongoDB
- Mongoose

AI:
- Embeddings
- Voyage AI
- Semantic Search

## Authentication

Implemented secure authentication using:

- Access tokens
- Refresh tokens
- HTTP-only cookies
- Express middleware
- Axios interceptors


**## Run Locally

Clone the repository

git clone https://github.com/sabatauqeer656/flow-desk.git

Install dependencies

npm install

Run frontend

npm run dev

Run backend

npm run start
